## Теоретическая часть

### Promise

`Promise` — это специальный объект для отложенных и асинхронных вычислений. Промис обещает уведомить о своём завершении, когда это произойдёт.

У промиса есть 3 состояния:
1. **Pending** — ожидание, результат ещё не известен
2. **Fulfilled** — промис выполнен успешно
3. **Rejected** — промис отклонён, произошла ошибка

### async/await

`async/await` — синтаксический сахар для работы с промисами, позволяющий писать асинхронный код в синхронном стиле.

### fetch

`fetch` — современная встроенная функция браузера для выполнения HTTP-запросов, возвращающая промис.

## Ход выполнения

### 1. Замена XMLHttpRequest на fetch

Файл `modules/ajax.js` переписан с использованием `fetch` и `async/await` вместо `XMLHttpRequest`:

- Методы `get`, `post`, `patch`, `delete` теперь возвращают промисы
- Вместо коллбеков используется `try/catch`
- Удалён метод `_handleResponse`, так как `fetch` обрабатывает ответ автоматически

### 2. Обновление страниц

Файлы `pages/main/index.js` и `pages/product/index.js` обновлены:

- Вместо передачи коллбека в `ajax.get()` используется `await`
- Методы `getData()` и `clickDelete()` стали асинхронными (`async`)
- Статус ответа проверяется через `response.ok` вместо `xhr.status`

### 3. Сборка клиентской части через Vite

Добавлена система сборки Vite:

- Создан `vite.config.js` с настройкой выходной директории `public`
- В `package.json` добавлены скрипты: `dev:client`, `build`, `preview`
- После сборки (`npm run build`) статические файлы генерируются в папку `public`

### 4. Раздача фронтенда в качестве статики

В `src/index.js` добавлена раздача статики из папки `public`:

```js
app.use(express.static(path.join(__dirname, '..', 'public')));
```

Это позволяет серверу раздавать собранный фронтенд без CORS-проблем.
