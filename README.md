## Теоретическая часть

### Three.js и GLTFLoader

Three.js — это библиотека для создания и отображения трёхмерной графики в веб-браузере. GLTFLoader — модуль для загрузки моделей в формате GLB (бинарная версия формата glTF), который является современным стандартом для веб-графики.

### IndexedDB

IndexedDB — это встроенный в браузер объектно-ориентированный индекс базы данных, позволяющий хранить структурированные данные на стороне клиента. В данном проекте используется для хранения загруженных пользователем 3D-моделей без необходимости отправки их на сервер.

### OrbitControls

OrbitControls — модуль Three.js, предоставляющий интерактивное управление камерой: вращение, масштабирование и панорамирование. Используется на странице детального просмотра.

## Ход выполнения

### 1. Структура проекта

Проект состоит из следующих файлов:
- `index.html` — главная страница с галереей карточек
- `detail.html` — страница детального просмотра одной модели
- `app.js` — логика галереи и загрузки пользовательских моделей
- `detail.js` — управление просмотром и камерой
- `idb.js` — обёртка для работы с IndexedDB
- `styles.css` — стили интерфейса

### 2. Главная страница (галерея)

На главной странице отображается сетка карточек (4 в ряду на десктопе) с 3D-превью моделей. Каждое превью — это миниатюрный canvas с отрендеренной моделью. Предусмотрены предустановленные модели (машина, деревья) и возможность загрузки своих GLB-файлов через форму в хедере.

### 3. Превью моделей

Превью рендерятся в отдельных canvas-элементах фиксированного размера (140×140 пикселей). Для корректного отображения модели автоматически центрируются: геометрия нормализуется так, чтобы основание модели совпадало с уровнем пола, а размер масштабируется для отображения в превью. Для парных моделей (например, «Машина + Дерево») обе модели отображаются в одном превью с отступом.

### 4. Детальный просмотр

При клике на карточку открывается страница `detail.html` с полноразмерным 3D-просмотром. Реализованы следующие функции управления:
- ручное вращение мышью (OrbitControls с включённым damping)
- кнопки «+» и «–» для приближения/отдаления камеры
- кнопки «Вид спереди / Сзади / Слева / Справа» для быстрой смены ракурса
- адаптивный ресайз при изменении размера окна браузера

### 5. Хранение пользовательских моделей

Загруженные пользователем GLB-файлы сохраняются в IndexedDB браузера. При загрузке файл читается как ArrayBuffer и сохраняется вместе с именем. При открытии страницы данные извлекаются и преобразуются обратно в буфер для парсинга через GLTFLoader.

## Особенности реализации

### Импорты через importmap

Все модули Three.js подключаются через importmap в head HTML-страниц, что позволяет использовать стандартный синтаксис ES6-импортов без сборки через bundler.

### Обработка ошибок загрузки

Если модель не может быть загружена (отсутствует файл, ошибка парсинга), вместо превью отображается заглушка с иконкой пазла.

### Центрирование моделей

Для корректного отображения используется алгоритм вычисления BoundingBox модели, после чего объект позиционируется так, чтобы его нижняя граница находилась на уровне Y = 0.
