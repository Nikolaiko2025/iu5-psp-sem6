## 2. Что такое node, npm и package.json

### Node.js

Node.js — это программная платформа, которая позволяет компилировать JavaScript код в машинный на компьютере. Node.js добавляет возможность взаимодействовать с устройствами ввода-вывода и подключать внешние библиотеки. На ней в основном пишут веб-сервера.

### Npm

Npm — пакетный менеджер для JavaScript. С помощью npm можно скачивать нужные пакеты, которые затем используются в приложении. Все библиотеки скачиваются в папку `node_modules`.

### Package.json и package-lock.json

Package.json — основной файл проекта, хранящий информацию о названии, описании, версии, скриптах и зависимостях. Package-lock.json хранит полное дерево зависимостей.

## 3. Как работать с html в JS

Для работы с HTML деревом используется DOM API. В данной работе применяются методы `getElementById` для получения элемента и `insertAdjacentHTML` для добавления верстки.

## 6. Простая кнопка на JavaScript

Добавлен корневой элемент `<div id="root">` в `index.html`. Создан файл `main.js`, который получает корневой элемент и добавляет в него кнопку с помощью `insertAdjacentHTML`.

**Файл main.js:**
```js
const root = document.getElementById('root');
root.insertAdjacentHTML('beforeend', '<button type="button" class="btn btn-primary">Hello world 2!</button>')
```

**Структура проекта:**

* `pages` — страницы приложения
* `components` — переиспользуемые компоненты

Создан класс `MainPage` в `pages/main/index.js` и компонент кнопки в `components/button/index.js`. В `main.js` импортируется и используется страница.

**Структура проекта:**
```bash

├── .gitignore

├── package.json
└── pages
    └── main
        └── index.js
└── components
    └── button
        └── index.js

├── main.js
```

## 8. Верстка главной страницы

Создан компонент карточки фильма `components/product-card/index.js` с версткой из Bootstrap. Компонент принимает данные (`data`) и обработчик клика (`listener`).

**Функции компонента:**
- `getHTML(data)` — возвращает HTML верстку карточки
- `addListeners(data, listener)` — подписка на событие клика
- `render(data, listener)` — отрисовка компонента

Создана главная страница `pages/main/index.js`:
- `getData()` — возвращает массив данных о фильмах (Интерстеллар, Начало, Побег из Шоушенка)
- `render()` — отрисовывает список карточек фильмов
- `clickCard(e)` — обработчик клика по карточке для перехода на страницу фильма

**Структура проекта:**
```bash
├── node_modules/
├── .gitignore
├── package-lock.json
├── package.json
└── pages
    └── main
        └── index.js
└── components
    └── product-card
        └── index.js
├── index.html
├── main.js
```
