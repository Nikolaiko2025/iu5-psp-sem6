## 2. Основы HTML

HTML (HyperText Markup Language) — это язык разметки гипертекста, который используется для создания веб-страниц. HTML описывает структуру документа с помощью тегов.

### Основные теги HTML

- `<html>` — корневой элемент документа
- `<head>` — метаинформация о странице
- `<body>` — видимое содержимое страницы
- `<header>` — верхняя часть страницы (шапка)
- `<nav>` — навигационное меню
- `<div>` — блочный контейнер
- `<a>` — ссылка
- `<ul>, <li>` — маркированный список
- `<img>` — изображение

## 5. Основы CSS

CSS (Cascading Style Sheets) — каскадные таблицы стилей, используемые для оформления HTML документов.

### Подключение CSS

Для подключения CSS используется тег `<link rel="stylesheet" href="style.css">` в секции `<head>`.

### Базовые стили

Создан файл `style.css` с базовыми стилями: сбросом отступов, настройкой шрифтов, градиентным фоном и анимациями.

## 6. CSS селекторы и каскадирование

Использованы различные типы селекторов:

- Селекторы тегов: `body`, `header`, `nav`
- Селекторы классов: `.header`, `.menu-link`, `.footer`
- Селекторы идентификаторов: `#result`
- Комбинированные селекторы: `.menu-list li`

### Каскадирование

Приоритет стилей: стили по умолчанию браузера, внешние стили из style.css, встроенные стили (inline), стили с `!important`.

## 7. Flexbox и Layout

Для создания адаптивной раскладки использован Flexbox. Контейнеры `container`, `menu-list`, `center-container` используют свойства `display: flex`, `align-items`, `justify-content` для выравнивания элементов.

**Flexbox позволяет:**
- Выравнивать элементы по горизонтали и вертикали
- Создавать адаптивные раскладки
- Управлять направлением и порядком элементов
