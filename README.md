## Теоретическая часть

### Express.js

Express.js — это минималистичный и гибкий веб-фреймворк для Node.js, предоставляющий мощный набор функций для быстрого создания веб-приложений и API. В то время как встроенный модуль `http` в Node.js предоставляет низкоуровневые инструменты, Express создает удобные абстракции над ним (маршрутизация, middleware, обработка ошибок).

### Ключевые особенности Express

- **Middleware-архитектура:** концепция цепочки функций-обработчиков, через которые проходит запрос
- **Роутинг:** мощная система маршрутизации для определения обработчиков по URL и HTTP-методам
- **Минималистичность:** не навязывает жесткую архитектуру, вы сами выбираете структуру

### Слоевая архитектура (Layered Architecture)

- **Router** — маршрутизация запросов
- **Controller** — обработка запросов и ответов
- **Service** — бизнес-логика
- **Data** — хранение данных (файл JSON)

## Ход выполнения

### 1. Создание проекта и базовая настройка

Инициализирован проект с помощью `npm init -y`. Установлен фреймворк Express.js и утилита `nodemon` для автоматического перезапуска сервера. В `package.json` добавлены скрипты запуска: `start` для production и `dev` для разработки.

Создана базовая точка входа `src/index.js` с настройкой Express-приложения, middleware для парсинга JSON и простым маршрутом для проверки работоспособности. После запуска сервер доступен по адресу `http://localhost:3000`.

### 2. Архитектура приложения (Layered Architecture)

Структура проекта организована по принципу слоевой архитектуры. В `src/` находится точка входа приложения. Папка `routes/` содержит маршрутизаторы. Папка `controllers/` содержит обработчики запросов. Папка `services/` содержит бизнес-логику и сервис для работы с файлами. Папка `data/` содержит JSON-файл с данными о фильмах.

Поток данных: Request попадает в index.js, проходит через middleware (логирование, парсинг JSON), попадает в Router, который вызывает Controller, Controller вызывает Service, Service выполняет бизнес-логику и возвращает данные, Controller формирует Response.

### 3. Реализация REST API для фильмов

#### Шаг 1: Данные (JSON-файл)

Создан файл `src/data/movies.json`, содержащий массив объектов-фильмов с полями: id, img (изображение), title (название), text (описание), badge (метка), badgeColor (цвет метки), rating (рейтинг), year (год), duration (длительность), country (страна), genres (жанры).

#### Шаг 2: FileService (Слой данных)

Создан переиспользуемый сервис `src/services/fileService.js`, предоставляющий методы `readData` для чтения файла и парсинга JSON, и `writeData` для записи данных в файл в формате JSON.

#### Шаг 3: MoviesService (Слой бизнес-логики)

Создан `src/services/moviesService.js` с методами: `init` для инициализации пути к файлу данных, `findAll` для получения всех фильмов с фильтрацией по названию, `findOne` для поиска фильма по ID, `create` для создания нового фильма с автогенерацией ID, `update` для обновления фильма, `remove` для удаления.

#### Шаг 4: MoviesController (Слой обработки запросов)

Создан `src/controllers/moviesController.js` с методами: `getAllMovies` получает все фильмы с фильтрацией по query-параметру title, `getMovieById` получает фильм по ID или возвращает 404, `createMovie` создает новый фильм с валидацией полей, `updateMovie` обновляет фильм или возвращает 404, `deleteMovie` удаляет фильм и возвращает 204.

#### Шаг 5: Routes (Маршрутизация)

Создан `src/routes/movies.js` с определением всех REST-маршрутов: GET `/movies/` — получение всех фильмов, POST `/movies` — создание фильма, GET `/movies/:id` — получение по ID, PATCH `/movies/:id` — обновление, DELETE `/movies/:id` — удаление.

#### Шаг 6: Подключение маршрутов (Entry Point)

В `src/index.js` собраны все компоненты: инициализирован сервис с путем к файлу данных, подключен middleware для парсинга JSON и логирующий middleware, подключен роутер фильмов по базовому пути `/movies`, настроена раздача статических файлов, добавлены обработчики 404 и error handler.

### 4. Тестирование API через Postman

Запущено приложение. Протестированы все REST-эндпоинты:

- **GET /movies/** — получение списка всех фильмов
- **GET /movies/?title=Интерстеллар** — поиск фильма по названию
- **GET /movies/?search=2014** — поиск по любому полю (где есть "2014" в title, year и т.д.)
- **GET /movies/?fields=title,rating** — вывод только указанных полей
- **GET /movies/:id** — получение фильма по ID
- **POST /movies** — создание нового фильма
- **PATCH /movies/:id** — обновление фильма
- **DELETE /movies/:id** — удаление фильма
