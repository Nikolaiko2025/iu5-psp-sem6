## Теоретическая часть

### XMLHttpRequest

`XMLHttpRequest` (или XHR) позволяет делать HTTP-запросы к серверу из браузера без перезагрузки страницы. Несмотря на наличие слова "XML" в названии, с помощью XHR можно работать с любыми типами данных, а не только с XML. С помощью XHR можно загружать/скачивать файлы, отслеживать прогресс загрузки и многое другое.

### CORS

При попытке выполнить XHR-запрос браузер может заблокировать запрос с другого домена. Такая политика ограничений называется CORS (Cross-Origin Resource Sharing). Для решения этой проблемы используется расширение CORS Unblock при разработке, а в продакшене — правильная настройка заголовков на сервере.

## Ход выполнения

### 1. Создание модуля URL-адресов

Создан файл `modules/stockUrls.js`, содержащий класс `StockUrls` для хранения всех эндпоинтов API:

- `getMovies()` — получение списка фильмов
- `getMoviesWithFilter(title)` — получение списка с фильтрацией по названию
- `getMovieById(id)` — получение фильма по ID
- `createMovie()` — создание нового фильма
- `removeMovieById(id)` — удаление фильма
- `updateMovieById(id)` — обновление фильма

### 2. Создание модуля AJAX

Создан файл `modules/ajax.js`, содержащий класс `Ajax` с методами для выполнения HTTP-запросов:

- `get(url, callback)` — GET-запрос
- `post(url, data, callback)` — POST-запрос
- `patch(url, data, callback)` — PATCH-запрос
- `delete(url, callback)` — DELETE-запрос

Каждый метод использует `XMLHttpRequest` и вызывает коллбек после завершения запроса.

### 3. Модификация главной страницы

Файл `pages/main/index.js` переработан для использования XHR вместо fetch:

- Добавлен импорт модулей `ajax` и `stockUrls`
- Метод `getData(title)` использует `ajax.get()` для получения списка фильмов
- Метод `renderData(items)` отрисовывает карточки из полученных данных

### 4. Создание компонента фильтрации

Создан файл `components/filter/index.js` с компонентом `FilterComponent`:

- Поле ввода для поиска по названию фильма
- При вводе текста отправляется GET-запрос с параметром `?title=...`
- Серверная фильтрация реализована в `moviesService.findAll(title)`

### 5. Модификация страницы карточки

Файл `pages/product/index.js` переработан для работы с API:

- Метод `getData()` использует `ajax.get()` для получения данных фильма
- Добавлена кнопка удаления фильма
- При клике на кнопку "Удалить" выполняется `ajax.delete()` запрос
- После успешного удаления выполняется переход на главную страницу

### 6. Выполнение индивидуального задания (1 вариант)

1. **Фильтрация карточек по названию** — реализована через компонент `FilterComponent` с передачей query-параметра `title` в GET-запрос на сервер
2. **Кнопка удаления карточки** — добавлена на странице фильма, выполняет DELETE-запрос к API `DELETE /movies/:id`
