## Теоретическая часть

### Массивы в JavaScript

Массив — это упорядоченная коллекция элементов, которая может хранить значения любых типов. Массивы в JavaScript являются динамическими и поддерживают множество встроенных методов для работы с данными.

### Объекты в JavaScript

Объект — это коллекция свойств, где каждое свойство состоит из пары ключ-значение. Объекты используются для хранения структурированных данных и поддерживают вложенность.

## Ход выполнения

### 1. Задачи 1 уровня сложности

#### 1.3 Сумма квадратов элементов массива

Реализована функция `sumOfSquares(arr)`, которая принимает массив чисел и возвращает сумму их квадратов. Для решения используется метод `reduce()`, который позволяет итерировать по массиву и накапливать результат.

```javascript
function sumOfSquares(arr) {
    return arr.reduce((sum, num) => sum + num * num, 0);
}
```

#### 1.8 Среднее арифметическое элементов массива

Реализована функция `average(arr)`, которая вычисляет среднее арифметическое всех элементов массива. Для пустого массива возвращается 0.

```javascript
function average(arr) {
    if (arr.length === 0) return 0;
    return arr.reduce((sum, num) => sum + num, 0) / arr.length;
}
```

### 2. Задачи 2 уровня сложности

#### 2.9 Проверка возможности получения одного массива из другого

Реализована функция `isEquivalent(arr1, arr2)`, которая проверяет, можно ли получить из одного массива другой каким-либо способом. Для решения используется подсчёт вхождений каждого элемента с помощью объекта-счётчика.

```javascript
function isEquivalent(arr1, arr2) {
    if (arr1.length !== arr2.length) return false;
    
    const count = {};
    for (const item of arr1) {
        count[item] = (count[item] || 0) + 1;
    }
    for (const item of arr2) {
        if (!count[item]) return false;
        count[item]--;
    }
    return true;
}
```

**Тесты:**
- `[1, 2, 3, 8, -2]` и `[2, 3, 8, 1, -2]` → `true`
- `[1, 2, 3]` и `[1, 2]` → `false`

### 3. Задачи 3 уровня сложности

#### 3.7 Flatten вложенного объекта

Реализована функция `plainify(obj, prefix)`, которая преобразует вложенный объект в плоский объект с dot notation для вложенных ключей. Функция использует рекурсию для обхода всех вложенных объектов.

```javascript
function plainify(obj, prefix = '') {
    const result = {};
    
    for (const key in obj) {
        if (!Object.prototype.hasOwnProperty.call(obj, key)) continue;
        
        const newKey = prefix ? `${prefix}.${key}` : key;
        const value = obj[key];
        
        if (value !== null && typeof value === 'object' && !Array.isArray(value)) {
            Object.assign(result, plainify(value, newKey));
        } else {
            result[newKey] = value;
        }
    }
    
    return result;
}
```

**Пример:**

```javascript
const nested = {
    a: {
        b: {
            c: 1
        },
        d: 2
    },
    e: 3
};
plainify(nested);
// { 'a.b.c': 1, 'a.d': 2, e: 3 }
```
