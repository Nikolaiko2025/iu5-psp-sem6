## 1. HTML-разметка

HTML - это язык разметки, с помощью которого описывается содержимое веб-страницы: текстовые поля, таблицы, кнопки, заголовки, ссылки. Для использования HTML-элементов на странице используются теги.

### Основные теги HTML

- `<html>` - корневой элемент документа
- `<head>` - метаинформация о странице
- `<body>` - видимое содержимое страницы
- `<div>` - блочный контейнер
- `<button>` - кнопка
- `<a>` - ссылка

Создан файл calculator.html со структурой калькулятора. Для каждого элемента определен уникальный идентификатор, необходимый для обращения к элементам из JavaScript.

## 5. CSS

CSS (Cascading Style Sheets) - каскадные таблицы стилей для кастомизации отображения HTML-элементов.

### CSS селекторы

1. Селектор элемента - применяет стили ко всем элементам указанного типа
2. Селектор по идентификатору (#id) - применяет стили к элементу с конкретным id
3. Селектор по классу (.class) - применяет стили к элементам с указанным классом

### Псевдоклассы

- :hover - состояние при наведении курсора
- :active - состояние при нажатии

## 6. Применение CSS к HTML-документу

CSS подключается через тег link в секции head. Создан отдельный файл style.css для хранения стилей.

## 7. Стилизация калькулятора

Создан файл style.css со следующими стилями:

- Базовые стили кнопки: размеры, скругление, цвет фона, шрифт
- Стили при наведении и нажатии: изменение фона и масштаба
- Классы операций: .secondary (серый) для второстепенных операций, .primary (оранжевый) для основных
- Класс .execute для кнопки "=" с увеличенной шириной
- Стили экрана результата: размеры, скругление, градиентный фон, выравнивание текста
